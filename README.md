# BRAVIA Remote 作業フォルダ

Sony Video & TV SideView 8.3.1 のリモコン経路を調査し、BRAVIA KJ-65X80J用の独立Androidリモコンを作成した作業フォルダです。

- 引き継ぎ資料: [引き継ぎ.md](引き継ぎ.md)
- 最新進捗: [進捗.md](進捗.md)
- アプリソース: [app/src/main](app/src/main)
- 生成APK: [BRAVIA-Remote-KJ-65X80J.apk](BRAVIA-Remote-KJ-65X80J.apk)
- SDK直接ビルド: `./build-manual.sh`

## 実装内容

- ダークテーマと押下時のAndroid触覚フィードバック
- 実物のリモコンを意識した十字キー、緑の電源キー、音量/チャンネルの縦配置、数字キー1〜12
- 歯車アイコンから開く専用設定ページ。接続先IPとPSKを端末内に保存
- 設定ボタンから設定項目一覧を表示し、接続設定・接続テスト・アプリ情報へ移動
- 入力切替タブでテレビの外部入力一覧を取得して切替
- 文字入力タブからテレビの画面上のソフトウェアキーボードへ文字送信
- IRCC-IPによる電源、入力、ホーム、音量、チャンネル、番組表、再生操作
- TVボタンはチューナー入力を取得し、REST APIで放送入力へ切り替え
- メディア操作に早戻し/再生/早送り、停止/一時停止、ヘルプ、録画リストを追加
- アプリタブからテレビに登録されたYouTube/Prime VideoアプリをREST API経由で起動
- 視聴予定の日時を残す「視聴メモ」
- ランチャーアイコン

アプリバージョン: `1.1.0`

ビルド: `./build-manual.sh`（SDK直接ビルド）

生成物: `BRAVIA-Remote-KJ-65X80J.apk`

## 録画予約について

KJ-65X80Jの録画予約はテレビの番組表から行います。本アプリの「番組表」はテレビに番組表キーを送る機能で、予約登録はテレビ画面上で完了してください。「視聴メモ」はこの端末に予定を記録する機能です。IRCC-IPは赤外線リモコン相当の操作を送る方式で、録画予約一覧の取得や外部からの録画予約登録には対応していません。

YouTube/Prime Videoの起動には、Sony REST APIの`getApplicationList`と`setActiveApp`を使用します。テレビ側のIPコントロール設定、PSK、対象アプリのインストール状況によって利用できない場合があります。

文字入力にはSony REST APIの`setTextForm`を使用します。テレビ側でソフトウェアキーボードが開いている間だけ入力できます。入力切替APIや文字入力APIがKJ-65X80J実機で利用可能かはまだ確認していません。

実機でのキー操作・通信確認はまだ行っていません。IPコントロールの設定やキー対応はテレビ側の状態によって異なる場合があります。
